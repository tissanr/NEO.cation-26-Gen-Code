# NEO.cation 26 · Gen Code

Übungsrepo für die Barcamp-Station **„Zerlegen, bauen lassen, abnehmen"** auf der NEO.cation 2026.

Dieses Repo ist **nicht** das Projekt, das wir in der Session bauen — das legt dein Agent am Tag selbst an. Hier geht es nur um eine Frage: **Läuft dein Setup?**

Das klingt nach Kleinigkeit, ist aber der größte Zeitfresser an so einem Vormittag. Wenn drei Leute morgens noch installieren, verliert die ganze Gruppe eine halbe Stunde. Deshalb: einmal vorher durchklicken, zehn Minuten, fertig.

## Los geht's — drei Schritte

**1 · Repo klonen**

```bash
git clone https://github.com/tissanr/NEO.cation-26-Gen-Code.git
cd NEO.cation-26-Gen-Code
```

Wenn das durchläuft, sind Git und dein Zugang schon erledigt.

**2 · Agenten starten** — in genau diesem Ordner. Claude Code oder Codex, beide sind freigegeben.

**3 · Und jetzt lass ihn arbeiten.** Sag ihm wörtlich:

> Lies SETUP.md und prüf, ob mein Setup vollständig ist. Sag mir am Ende, was fehlt.

**4 · Ergebnis zurückschicken.** Kopier die Tabelle, die dabei herauskommt, in deine Antwort auf die Anmeldemail. Fertig.

Das ist der ganze Aufwand. Du bekommst eine Tabelle mit Häkchen und Lücken, und wir wissen vorher, wo es klemmt — statt am Vormittag der Session.

**Wenn dein Agent gar nicht erst startet:** auch das ist ein Ergebnis, und zwar ein wichtiges. Schreib einfach, woran es scheitert.

## Warum wir das so machen

Weil es die Kernbotschaft der Station im Kleinen ist: **Was du über das Werkzeug wissen musst, kannst du das Werkzeug fragen — auch das Setup.** Du hättest die Liste in `SETUP.md` auch selbst durcharbeiten können. Der Agent macht es in einem Zug, und du hast deine erste echte Begegnung mit ihm hinter dir, bevor es losgeht.

Nebenbei: Die Datei `CLAUDE.md` in diesem Ordner ist der Grund, warum der Agent überhaupt weiß, was er hier tun soll. So eine Datei schreibst du in der Session selbst — dann für dein eigenes Projekt.

## Wenn was klemmt

Melde dich **vorher**, nicht am Tag selbst. Der häufigste Stolperstein ist der Firmenproxy, der beim ersten Download auffällt und nicht bei der Installation. Zweithäufigster: „installiert" heißt nicht „läuft" — Login und Lizenz fallen erst beim ersten Aufruf auf.

## Der Ordner `spielwiese/`

Zum Kaputtmachen. Lass deinen Agenten dort etwas anlegen, ändern, löschen. Nichts davon ist wichtig, und genau das ist der Punkt.
